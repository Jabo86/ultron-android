# Community code of conduct

UNVOR aims to support respectful, constructive collaboration across languages, backgrounds and levels of experience.

Be kind, address technical disagreements with evidence, respect privacy, and acknowledge mistakes. Harassment, discrimination, threats, impersonation, disclosure of private information and deliberate disruption are unacceptable.

For ordinary moderation concerns, contact repository maintainers through an appropriate private channel. Do not post sensitive reports publicly. Maintainers should review concerns fairly, protect confidentiality where possible, and take proportionate action within the repository. Security vulnerabilities follow [SECURITY.md](SECURITY.md).

This document does not grant permission to test other people's accounts, devices or infrastructure.
