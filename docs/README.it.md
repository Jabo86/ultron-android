# UNVOR — Ecosistema Android indipendente

[English](../README.md) · [Español](README.es.md) · [Documentazione](README.md)

UNVOR comprende un client di messaggistica Android, un Launcher e un progetto di federazione dei nodi. L'obiettivo è ridurre le dipendenze obbligatorie dai servizi Google e dalle infrastrutture centralizzate. Il Launcher è progettato per GrapheneOS; non è un sistema operativo né un prodotto ufficiale GrapheneOS.
