# Roadmap

Status categories: **present** = repository evidence exists; **in development** = work exists but acceptance is incomplete; **planned** = not yet delivered in this roadmap. Dates are not commitments.

## Foundation

- [x] Existing public Android repository and pilot releases.
- [x] Launcher source located in a development branch.
- [x] Initial multilingual repository presentation and documentation.
- [ ] Review ownership, third-party obligations and transition to an approved open-source license.
- [ ] Approve final UNVOR visual assets and publish authentic sanitized screenshots.
- [ ] Establish a confirmed UNVOR security contact and governance.

## Product acceptance

- [ ] Verify Chat send/receive, retries, attachments, calls and background notification behavior on real devices.
- [ ] Verify Launcher installation, upgrades, device compatibility, local features and dependency provenance.
- [ ] Verify node federation, failure recovery, data retention and metadata boundaries.
- [ ] Establish release-specific evidence for Google-service independence.

## Distribution

- [ ] Separate stable and experimental channels.
- [ ] Publish signed APKs with source commit, digest, certificate fingerprint and release notes.
- [ ] Review reproducibility and dependency audit results.
- [ ] Publish multilingual web portal linking to canonical releases.
- [ ] Decide whether to retain a monorepo or establish dedicated repositories, preserving history and attribution.

See [release checklist](RELEASE-CHECKLIST.md).
