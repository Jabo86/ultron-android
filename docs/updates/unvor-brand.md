# UNVOR brand migration

Both Chat and the Pixel launcher use the supplied UNVOR logo and matching black/cyan home artwork. Chat gets a new home with real navigation and unread/contact-request badges. The launcher keeps app shortcuts, local agenda/shifts, alarms, voice controls and per-app choices.

Visible copy, translated documents, app labels, incoming-call panels and notification titles use UNVOR. Android notification status icons use a monochrome U/Earth glyph and expanded notices carry the supplied full-color logo. Watch notifications use Android notification mirroring; there is no separate watch app in this project and watch presentation needs device testing.

Application IDs, signing identity, private storage keys, encrypted backup formats, existing account addresses, QR protocol identifiers and cryptographic domain separators remain compatible with the previous versions. New group links use unvor:// while the old ultron:// scheme remains accepted. No new server migration is needed for the visual brand change.

The launcher shows real RAM, battery and storage information; CPU and weather are unavailable unless supported by an actual provider, never filled with sample values. Device information does not certify OS integrity. The microphone still uses the existing local command system; no new conversational AI is claimed.

Required device checks: upgrade in place; unlock an existing account; read previous chats; send/receive and choose/cancel files; accept contact requests; receive native call and message alerts; inspect mirrored watch notifications; exercise launcher shortcuts and retained local agenda.
