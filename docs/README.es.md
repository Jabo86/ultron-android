# UNVOR — Ecosistema Android independiente

[English](../README.md) · [Italiano](README.it.md) · [Documentación](README.md)

UNVOR comprende un cliente de mensajería Android, un lanzador y un proyecto de federación de nodos. Su objetivo es reducir la dependencia obligatoria de los servicios de Google y de la infraestructura centralizada. El lanzador está orientado a GrapheneOS; no es un sistema operativo ni un producto oficial de GrapheneOS.
