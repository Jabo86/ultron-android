# Contributing to UNVOR

Thank you for considering a contribution. The project is currently source-available under [BSL 1.1](LICENSE); review the applicable terms before contributing or redistributing. A future open-source license transition requires maintainer review.

1. Read the [architecture](docs/ARCHITECTURE.md) and [roadmap](docs/ROADMAP.md).
2. Use [issues](https://github.com/Jabo86/ultron-android/issues/new/choose) for ordinary bugs or proposals. Vulnerabilities must be reported privately via [SECURITY.md](SECURITY.md).
3. Work on a focused branch from the appropriate base. Keep unrelated changes separate.
4. Explain the change, affected components, evidence and limitations. Include reproducible tests for behavior changes.
5. Do not commit signing keys, account credentials, private conversations, personal identifiers, private configuration or undocumented third-party binaries.
6. Open a pull request for review. Preserve required attributions and identify new dependency licenses.

Use the [code of conduct](CODE_OF_CONDUCT.md). English, Italian and Spanish reports are welcome. Do not claim certification or production readiness based solely on static tests.
